# 🛡️ Xeno Anti-Abuse Bot

Ek powerful Telegram bot jo aapke group ko gandi bhasha aur abuse se bachata hai.

## ✨ Features
- ✅ **Auto Delete**: Gali wale messages turant delete karta hai.
- ✅ **3-Warn System**: 3 baar gali dene par automatic Mute.
- ✅ **Admin Bypass**: Admins aur Owner par filter kaam nahi karega.
- ✅ **Inline Buttons**: Support aur Update links ke saath.

## 🚀 Deployment
1. GitHub par fork karein.
2. Render.com par account banayein.
3. Repo connect karein aur `API_ID`, `API_HASH`, `BOT_TOKEN` dalein.
4. Deploy par click karein!
